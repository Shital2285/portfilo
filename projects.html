AgroVani – Voice-Enabled Farming Assistant

AgroVani helps farmers access agricultural information in Marathi, with a focus on the Solapur regional dialect. Voice recognition and natural language processing make it easier to get guidance without needing to read or type.

Key Features

  • Voice-based farming questions in Marathi and regional language support
  • Weather forecasts, crop cultivation guidance, mandi prices, and government scheme information
  • Fertilizer calculator, Krushi Doctor guidance, and crop disease detection from leaf images

Technologies: Flutter, Python, Flask, Dialogflow, Google Speech-to-Text, Text-to-Speech, Weather and Agricultural APIs

POMELO – AI-Based Pomegranate Disease Detection System

POMELO is a multilingual web application that analyzes uploaded pomegranate leaf images using the EfficientNet-B0 deep learning model. It displays the predicted disease class and the model's confidence score.

Key Features

  • Classifies leaves as Healthy, Bacterial Blight, Anthracnose, Cercospora, or Alternaria
  • Image-based analysis with prediction confidence scores
  • Accessible in Marathi, Hindi, and English

Technologies: EfficientNet-B0, Deep Learning, Artificial Intelligence, Computer Vision, Node.js, Express.js, MongoDB, HTML, CSS, JavaScript
